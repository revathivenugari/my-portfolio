01 Apt PathReact · Micro Frontend · MUI · Tailwind A large-scale education platform decomposed into independently deployable micro frontends with secure, role-based authentication. +

Designed and implemented a micro frontend architecture using Module Federation — splitting the platform into independent, team-owned apps that could be built, tested, and deployed without touching each other. Wired it all together with a centralized JWT authentication layer so every role gets exactly the access it should have, and nothing more.

What I did

  • Architected a micro frontend system using Webpack Module Federation, splitting the app into independently deployable modules — Student, Teacher, Admin, and Content — each owned and deployed by separate teams.
  • Built a centralized JWT authentication flow: login, token refresh, secure storage, and automatic logout on expiry — so every micro app shared one auth layer without duplicating logic.
  • Implemented role-based access control (RBAC) to gate routes and UI elements by user role — students can't see admin panels, teachers can't touch content management, and so on.
  • Created a shared component library (MUI + Tailwind) consumed by all micro apps to keep the UI consistent across module boundaries without tight coupling.
  • Integrated multiple backend APIs per module via Axios, with centralized request interceptors for auth headers and error handling.
  • Coordinated the micro frontend shell architecture with backend and DevOps teams to ensure the host app loaded remote modules reliably in staging and production.
